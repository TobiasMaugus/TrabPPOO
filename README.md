# Instruções de Compilação e Execução

### 🧩 Compilação

```bash
javac -d bin src/*.java
```

### ▶️ Execução

```bash
java -cp bin Principal
```

---

## 📄 Arquivos de Exemplo

O repositório contém arquivos de exemplo de configuração:

- `config_example.txt`
- `config_variant.txt`

Se desejar criar um novo arquivo de configuração, siga o formato de um dos exemplos acima ou utilize o modelo:

- `template.txt`
